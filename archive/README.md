# Archive: Legacy and Review-Only Material

This directory contains material from earlier iterations, review cycles, or exploratory work that is not part of the canonical documentation set.

## Purpose

These files are preserved for historical reference and audit trail, but are **not part of the official repository structure** as defined in the root `README.md`.

## Contents (from main branch before reorganization)

- Historical versions of research framework documents
- Technical review and diagnostic notes
- Validation audit reports
- Earlier naming conventions of benchmark and implementation specs

## Usage

If you need to refer to an archived document:

1. Check the corresponding canonical file in `docs/` first
2. Use archive files only for historical context or version tracking
3. Do not link to archive files from official documentation

## Note

The canonical documentation always resides in `docs/` and is the single source of truth for the project.
